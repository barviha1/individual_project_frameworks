# Система управления кадровыми документами

## Назначение

Приложение предназначено для автоматизации учёта и хранения кадровых документов сотрудников организации. Оно решает задачу централизованного хранения документов, их классификации по категориям и контроля сроков действия, чтобы кадровая служба могла быстро находить нужный документ и не пропускала даты.

## Целевая аудитория

- HR-специалисты и сотрудники отдела кадров, ведущие документооборот по персоналу;
- руководители подразделений, которым требуется доступ к документам своих сотрудников;
- сотрудники организации — для просмотра статуса и сроков действия собственных документов (в перспективе, при развитии проекта).

## Предметная область

Кадровое делопроизводство: ведение личных дел сотрудников, хранение и систематизация связанных с ними документов, отслеживание сроков действия документов и своевременное информирование о приближающихся датах (истечение договора, необходимость продления справки, окончание испытательного срока и т.д.).

## Основные сущности

- Сотрудник — ФИО, должность, отдел, дата приёма на работу, контактные данные; связан с одним или несколькими документами.
- Документ — название, тип/категория, файл или путь к файлу, дата создания, дата окончания срока действия (если применимо), сотрудник, к которому относится документ.
- Категория — тип документа (трудовой договор, приказ, справка, аттестационный лист, медицинская книжка и т.д.), используется для классификации и фильтрации документов.
- Срок — дата начала и дата окончания действия документа, статус (активен / истекает / истёк), привязка к конкретному документу и сотруднику.

## Основные функции

- Добавление, редактирование и удаление карточек сотрудников;
- добавление документов с привязкой к сотруднику и категории;
- управление категориями документов (создание, редактирование, удаление);
- отслеживание сроков действия документов и автоматическое определение их статуса (активен / скоро истекает / истёк);
- поиск и фильтрация документов по сотруднику, категории и статусу срока;
- формирование сводных отчётов, например список документов с истекающим или истёкшим сроком действия.

## План развития

На следующих этапах планируется:

- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
