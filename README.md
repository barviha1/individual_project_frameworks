# Система управления кадровыми документами

Консольное приложение для учёта сотрудников, кадровых документов
и контроля сроков их действия.

## Назначение

Приложение предназначено для автоматизации учёта и хранения кадровых документов
сотрудников организации. Оно решает задачу централизованного хранения документов
(трудовых договоров, приказов, справок и т.п.), их классификации по категориям
и контроля сроков действия — чтобы кадровая служба могла быстро находить нужный
документ и не пропускала даты, требующие внимания.

## Целевая аудитория

- HR-специалисты и сотрудники отдела кадров;
- руководители подразделений;
- сотрудники организации — для просмотра статуса и сроков действия своих документов
  (в перспективе).

## Предметная область

Кадровое делопроизводство: учёт сотрудников, хранение и систематизация связанных
с ними документов, отслеживание сроков действия документов и своевременное
информирование о приближающихся датах.

## Основные сущности

- **Сотрудник** — id, ФИО, должность, отдел, дата приёма.
- **Документ** — id, название, категория, id сотрудника, срок действия.
- **Категория** — название и описание типа документа.
- **Срок** — вычисляется по дате истечения документа: активен / скоро истекает / истёк.

## Возможности (реализовано на ПР2)

- добавление, поиск, редактирование и удаление карточек сотрудников;
- добавление документов с привязкой к сотруднику и категории;
- создание, редактирование и удаление категорий документов;
- отслеживание сроков действия документов и автоматическое определение статуса
  (активен / скоро истекает / истёк);
- поиск и фильтрация документов по сотруднику и по категории;
- статистика по документам и отдельный список документов с истекающим сроком;
- сохранение и загрузка всех данных в JSON-файлах;
- обработка некорректного ввода пользователя и ошибок при чтении файлов данных.

## Структура проекта

```

├── main.py          — точка запуска, меню приложения
├── employees.py     — работа с сотрудниками

├── categories.py     — управление категориями документов
├── storage.py         — сохранение и загрузка данных (JSON)
```

## Формат хранения данных

Данные хранятся в каталоге `data/` в формате JSON:

- `employees.json` — словарь сотрудников (ключ — id сотрудника);
- `documents.json` — список документов;
- `categories.json` — словарь категорий (название → описание).
